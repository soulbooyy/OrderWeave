## 规划链路

同一次意图识别调用生成六类主意图和子任务。DAG prompt 使用 Pydantic 生成的 JSON Schema 和经模型校验的完整示例，要求返回单个 JSON 对象。严格 JSON 解码拒绝围栏、多对象、重复键和非有限数；Pydantic 拒绝额外字段、类型错误、缺失的 subtasks 或必填节点字段。target 必须显式给出，由前驱推导时填写空字符串。run_if 使用前驱 ID 和 then/else。程序从用户原文定位唯一条件，将验证过的条件编译回执行器使用的格式，沿用有向无环、原文引用及输出来源等检查。运行权限、真实工具证据和交易确认仍由执行路径核验。[Pydantic 模型](../../../core/dag_schema.py) · [JSON Schema](schema.json) · [真实中文输出示例](example.json) · [解析与编译](../../../core/dag_planning.py)

首次 JSON、结构或语义失败时，分类器将原始用户需求、上次完整输出和带字段路径的错误交回同一个模型，至多再请求一次完整 JSON。第二次仍失败时在角色派发前停止。两次均经正常客户端预留和结算。账本或轮次上限拒绝会向上抛出。未使用规划工具调用；本次真实验证的客户端为 DeepSeek。[意图识别与纠错](../../../core/intent_recognizer.py) · [派发前处理](../../../agents/agent_orchestrator.py)
