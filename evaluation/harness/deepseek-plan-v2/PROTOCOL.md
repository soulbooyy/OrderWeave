# 新题规划验收 v2

10 个新用户输入，每题使用独立的空历史。其中 8 个有可执行计划，2 个包含超出支持语法的条件，预期拒绝。输入文件独立，金标只在离线计分时使用。本次只测规划，不查询业务库或发起真实交易。复用已安装的真实分类器，一题最多 2 请求，保留首次和末次原始响应、错误路径、用量和墙钟时间。预算从历史已结算 ¥4.95901620 起算，累计上限 ¥10。

在 8 道可执行题上分别报首轮 JSON、结构、语义通过率、最终通过率、整图匹配，以及末次节点和边的微平均 P/R/F1、条件正确数/金标数。解析失败或缺失任务按无预测处理；拒绝仍在分母，整图要求最终通过。原始与订单号归一化两版评分并存。2 道应拒题单列，结构/语义拒绝才能记正确，基础设施或预算中止不能记正确。P50 为中位数，P95 为最近秩；费用按账本真实用量及人民币缓存分价估算，含所有纠错。

本次约定进入端到端的门槛为：可执行计划首次语义通过至少 7/8，最终通过 8/8，整图匹配至少 7/8，全部金标条件分支正确，2 道应拒题均被拒绝。每题抽样一次，达标只支持启动端到端评测。门槛和题目在首次网络调用之前用 Git 冻结。已发布的 v1 六题用于回归，不进入分母。模型配置为 deepseek-flash、thinking disabled、温度 0.1、输出上限 2048；每次单独向官方 API 发送当前题，语言跟随题面。
